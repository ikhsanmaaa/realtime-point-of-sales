# Cafe App – Realtime Point of Sales (POS)

A realtime Point of Sales (POS) web application built using Next.js and Supabase Realtime.  
This project simulates a modern cafe ordering system with live order updates, payment gateway integration, and interactive seat-based ordering.

Live Demo: https://realtime-point-of-sales-seven.vercel.app/

##  Features

- Interactive seat-based ordering system (built with @xyflow/react)
- Realtime order updates using Supabase Realtime
- Create and manage customer orders
- Payment integration using Midtrans
- Sales dashboard with order analytics
- Live synchronization of transaction data

---
